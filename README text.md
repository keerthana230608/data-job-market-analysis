# Data Job Market Analysis

An exploratory analysis of 2023 data job postings, focused on skills, remote work, and location.

## Questions
- Which skills appear most often in Data Analyst and Data Scientist postings?
- How do skill requirements differ between these roles?
- What share of postings are marked remote?
- Which countries are most represented in the postings analyzed?

## Dataset
[Luke Barousse’s data jobs dataset](https://huggingface.co/datasets/lukebarousse/data_jobs), containing job postings from 2023.

## Methods
- Filtered postings to selected analyst and scientist roles
- Counted each skill once per posting
- Compared the share of postings mentioning each skill
- Summarized remote-work share and country counts
